# Hi, I'm Charissa

Accountant, builder, coach.  Curious about how work gets done, compassionate with the people doing it, and I empower them to change it.

I'm a CPA-qualified (Australia) accountant and a self-taught finance data engineer, based in Berlin.  Most people building finance systems come from the technology side.  I came from the business side, so I know what a number means before I write the query.

## How I work with AI

I'm not a coder, and I don't pretend to be.  I direct AI to write the code, and I check every piece against standards I set: naming conventions, validation rules, reconciliation back to the source system, and documentation written as I build, not after.  The accountant in me doesn't trust a number until it ties out, and I hold AI output to the same standard.

That's how I built a governed general ledger data platform in Databricks, from the raw SAP layer up, with a formal certification path every object goes through before anyone relies on it.
